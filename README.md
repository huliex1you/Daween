# دوّن - مشروع APK

1. ارفع كل محتويات هذا المجلد إلى مستودع GitHub (بما فيها المجلدات المخفية .github و android-res و assets).
2. افتح Actions ثم Build APK ثم Run workflow.
3. بعد اكتمال البناء نزّل dawwin-apk من قسم Artifacts وثبّت app-debug.apk على الجوال.

## الشعار
- أيقونات التطبيق بكل المقاسات في android-res، وتُنسخ تلقائياً أثناء البناء.
- الشعار الأصلي بدقة 1024 في assets/icon.png.

## الذكاء الاصطناعي داخل التطبيق
- افتح التطبيق ثم الحساب ثم بطاقة «الذكاء الاصطناعي».
- الصق مفتاح Claude API (من console.anthropic.com) ثم «اختبار الاتصال» ثم «حفظ».
- المفتاح يُحفظ على الجهاز فقط ولا يدخل في النسخة الاحتياطية.

## النسخ الاحتياطي
- يستخدم التطبيق إضافتي @capacitor/filesystem و @capacitor/share (تُثبَّتان تلقائياً أثناء البناء).
- «إرسال إلى البريد» يفتح قائمة المشاركة والملف مرفق، و«حفظ في الجهاز» يحفظه في مجلد المستندات (Documents).
